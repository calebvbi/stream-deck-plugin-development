# Changelog

All notable public changes to this project are documented here.

## 0.1.0-rc.3 - 2026-08-27

- Added end-to-end guidance for new and existing Stream Deck plugins.
- Added task routing for manifests, actions, keys, dials, Neo, Property Inspectors, settings, profiles, platform services, troubleshooting, packaging, and QA.
- Added bounded animation rules for ownership, finite work, backpressure, write-rate limits, lifecycle cancellation, and idle quiescence.
- Added compatibility-floor preservation and source-of-truth guidance for existing plugins.
- Added standard-library helpers for project inspection, QA matrix generation, and Property Inspector self-containment validation.
- Hardened generated-report class names and output paths against HTML attribute injection, symlink redirection, and leaf write races.
- Rejected inline executable documents and executable data URLs in Property Inspector closure checks.
- Pinned documented installation commands to the release tag and tested installer version.
- Added evidence boundaries for source, package, installed runtime, simulated input, and physical hardware.
- Added a portable public repository layout and deterministic publication validation.
